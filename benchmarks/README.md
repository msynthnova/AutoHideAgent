# Retained benchmark results

See [the November 13 comparison](results/2026-11-13/REPORT.md).
The JSON files contain calibrated process measurements, not simulations.
The paired baseline and updated runs each include three 20-second samples for
five steady scenarios. The separate baseline burst run adds 20 ms memory sampling;
the updated full run uses the same burst sampler. These are local working-desktop
measurements, not a cross-machine performance guarantee.

Reproduction and regression budgets are documented in [PERFORMANCE.md](../PERFORMANCE.md).
